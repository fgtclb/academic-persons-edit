Stands in for a project's own template override, and reads the one view variable an override may read that Extbase does not provide by itself. `f:render.text` refuses anything but a record object, which is exactly how TYPO3 v14's header partial of EXT:fluid_styled_content reads the header - so a controller that stops assigning `record` fails here, on both core versions, instead of only in a v14 frontend.
