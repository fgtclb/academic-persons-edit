The question asked before an editor with unsaved changes is closed for another one, as a template. "data-pe-dialog" rather than "data-pe-proto": the dialog is cloned whole, with nothing to fill, so it is not one of the prototypes of Profile/Prototypes.html and is not counted among them. Only one editor of the profile is open at a time - a field, a group, the whole form, a document row or a contact. Opening another one closes the one that is open, and when that one holds changes "Resources/Private/TypeScript/frontend/profile/editors.ts" clones this dialog, shows it modally and reads the answer off the button that was pressed: "save" stores the open editor first, "discard" throws the changes away, "cancel" (and Escape) opens nothing. A native window.confirm() would not do: it cannot carry three answers, cannot be translated by this file and can be suppressed by the browser. The three "data-pe-unsaved-choice" values and "data-pe-unsaved-changes" are the contract; the tags, classes and labels are this file's.
