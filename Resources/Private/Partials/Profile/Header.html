{profile.{field.propertyName}}

The one form control of the editor that is not rendered through Profile/Field/Control.html. It is not a profile field: it deliberately carries the "__sync-checkbox" class and not the "__field" one, because frontend/profile/fields.ts collects the latter and would then save and validate the switch as if it were a mapped property. It is spelled once, with the same "disabled" expression Control.html uses, so read-only and disabled cannot drift apart.
