The one form control of the editor that is not rendered through Profile/Field/Control.html. It is not a profile field: it deliberately carries the sync hook and not the field-control hook, because frontend/profile/fields.ts collects the latter and would then save and validate the switch as if it were a mapped property. It is spelled once, with the same "disabled" expression Control.html uses, so read-only and disabled cannot drift apart.
The owner's "Show my profile publicly" switch. Like the synchronisation switch above it is not a profile field, so it carries its own behaviour hook and not the field-control hook. It shows the profile's "hidden" column inverted: it is on while the profile is public.
